# Spec 0006 amendment 3: the resting card opens Craft too

Status: accepted
Amends: [spec 0006](0006-more-screens.md) §2.1 (the resting card's "Open the map" button)
Product owner: Zkalf (asked for it, 2026-10-20)
Date: 2026-10-20

## Change
1. While resting, the Now screen's card has an **Open Craft** button next to **Open the map**, for consistency:
   the text already points to both screens.
2. Before the first recipe opens (level 3) there is no Craft screen (amendment 1), so the card shows only the map
   button and says "Pick something to do on the Map."

## Acceptance criteria
While resting, a button opens the Map and, from the first recipe, another opens Craft; before that, the card neither
shows a Craft button nor mentions the Craft screen.
